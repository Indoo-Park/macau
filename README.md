# Gastro Atlas · 마카오 맛집 백과사전

여행자이자 미식가를 위한 마카오 맛집 백과사전. 단일 HTML 파일(`index.html`)로, 브라우저에서 열면 바로 쓸 수 있다.

**수록:** 마카오 32곳 · 반도 / 타이파 / 코타이 / 콜로안

## 기능

- **주제별 탐색**: 마카니즈 · 포르투갈 · 에그타르트 · 딤섬/광둥 · 국수/죽 · 길거리 간식 · 미쉐린/파인다이닝 · 디저트/카페
- **상황 필터**: 혼밥 · 가성비 · 데이트 · 단체 · 줄서는집 · 현금만 · 야식
- 지역 · 예산 · 정렬 필터와 통합 검색 (`/` 키로 바로 검색)
- **상세 정보**: 대표 메뉴와 가격(MOP + 원화 어림값), 미식가 팁, 구글 지도 길찾기
- **주변 맛집 연결**: 가장 가까운 4곳을 도보/차량 시간과 함께 추천
- **맛집 지도**: 카테고리별 색상 점, 필터 연동
- **찜 목록**: 브라우저에 저장
- 현지 결제 · 봉사료 · 이동 동선 · 주문 회화 꿀팁

## 사용법

`index.html`을 다운로드해 브라우저로 열거나, GitHub Pages 주소로 접속한다.

> 가격은 2025~2026년 기준 어림값이며, 영업시간·휴무일은 방문 전 구글 지도에서 확인할 것.
